> **NULL** is a special value in SQL that represents the absence of data or an unknown value.

## Characteristics of NULL:

- `NULL` is not equivalent to an empty string or zero.
- Arithmetic, comparisons, and most functions return `NULL` when one of the operands is `NULL`: `5 + NULL` is `NULL`.
- Comparing `NULL = NULL` also returns `NULL`, not `true`: it is unknown whether two unknown values are equal. That is why `WHERE field = NULL` finds no rows — use `IS NULL` instead.
- Logical operators are an exception: `NULL OR true` returns `true`, and `NULL AND false` returns `false`.

## Working with NULL

To check for `NULL`, use the `IS NULL` or `IS NOT NULL` operator.

```sql
-- Finding records with an unknown birth date
SELECT * FROM employees WHERE birth_date IS NULL;

-- Finding records with a known birth date
SELECT * FROM employees WHERE birth_date IS NOT NULL;
```

## Functions for working with NULL

- <a href="https://sql-academy.org/en/handbook/COALESCE" target="_blank">
    **COALESCE**
  </a>

    Returns the first non-`NULL` value from the list.

    ```sql
    COALESCE(val1[, val2, ...., val_n])
    ```

- <a href="https://sql-academy.org/en/handbook/ISNULL" target="_blank">
    **ISNULL**
  </a>

    Returns `1` or `0` depending on whether the expression is `NULL`.

    ```sql
    ISNULL(value)
    ```

- <a href="https://sql-academy.org/en/handbook/IFNULL" target="_blank">
    **IFNULL**
  </a>

    Returns the first argument if it is not `NULL`. Otherwise, it returns the second
    argument.

    ```sql
    IFNULL(value, alternative_value)
    ```

For a deeper dive with examples, see the article [“SQL COALESCE: Replacing NULL and the NULLIF Combo”](https://sql-academy.org/en/blog/sql-coalesce).
